3-in-1 Restaurant Voice Agent System

An AI-powered restaurant voice automation project designed to handle customer calls, reservations, menu inquiries, and order-related tasks.

Project Overview

This project showcases a restaurant voice agent system designed for Criniti’s Italian restaurant, with a concept covering 10 locations across Sydney, Melbourne, and Perth.

The system aims to help restaurants manage customer inquiries and bookings automatically, including outside regular business hours.

Key Features

* Table Reservations: Accepts reservation requests and saves booking information to Google Sheets.
* Menu Assistance: Answers questions about menu items and current offers.
* Order Handling: Collects customer orders and supports automated email confirmations.
* Group Bookings: Supports birthday, corporate, and group booking inquiries.
* Workflow Automation: Connects voice-agent functionality with spreadsheets and email workflows.
* Always-On Availability: Designed to handle customer requests 24/7.

Technology Stack

* Retell AI
* Make.com
* Google Sheets
* Gmail API
* Webhooks
* JSON Schema

Workflow

1. A customer calls the restaurant.
2. The AI voice agent responds to the customer’s questions.
3. The agent collects relevant booking or order details.
4. The workflow sends the collected information to the appropriate system.
5. Reservation details are saved to Google Sheets, and email confirmations can be sent when configured.

Potential Benefits

* Reduces repetitive phone-handling tasks.
* Helps restaurants manage inquiries after closing time.
* Organizes reservation and order information.
* Supports consistent customer service.
* Can be adapted to multiple restaurant locations.
